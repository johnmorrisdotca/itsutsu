# 5×5 matrix i

The matrix uses the supplied pattern with `x` as a black marble and `o` as an ivory marble:

```text
x x o x x
x x x x x
x x o x x
x x o x x
x x o x x
```

Every cell is a marble. The x-cells are black and the o-cells are ivory; their center-column arrangement creates the i-shaped contrast. Both marble colors have contrasting 3-unit borders. Both SVGs use a 240 × 240 rounded square (`rx=28`) and the shared hero marble geometry: 15-unit radius, 5-unit border, and 42-unit center spacing. The light version uses charcoal dots on ivory; the dark version keeps black dots on charcoal with a thick ivory border so the black centers remain visible.

Ivory marbles use an ivory outer edge to preserve their apparent size at small display sizes; black marbles use ivory outlines for contrast.

On the light background, ivory marbles use charcoal borders. On the dark background, ivory marbles use ivory borders so they do not appear undersized against charcoal.
