# Changelog

## 0.1.0

- A cube of any size from 2×2, as a string of stickers turned by pure functions.
- Standard notation read and written: faces, inner layers (`2R`), middles (`M E S`), whole-cube turns (`x y z`).
- Seedable scrambles.
- `CubeView`: the cube in CSS 3D, turned by drag, mouse wheel (Ctrl and Shift for the other layers), touch and keys, with animated turns.
- `Kyuubu`, a React component around `CubeView`.
