# Code of Conduct

Kyuubu follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, be patient, and assume good faith. Harassment, personal attacks and discriminatory language aren't welcome in issues, pull requests or anywhere else the project lives.

If something happens that you'd like to report, open an issue marked **conduct**, or contact the maintainer through their [GitHub profile](https://github.com/johnmorrisdotca). Reports are handled privately.
