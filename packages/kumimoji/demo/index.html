Kumimoji組み文字

One crossword from every tile in the bag.

GitHub Docs npm
Tap a tile in your hand, then a square. Tap a tile on the table to move it, or twice to take it back. When your hand is empty and every run is a word, draw the next tile. Open source under the MIT licence, by John Morris; the English words are from SCOWL and the Japanese from JMdict (CC BY-SA 4.0), as set out here.
