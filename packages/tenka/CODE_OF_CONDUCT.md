# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, be patient, assume good faith, and keep discussion about the
work. Harassment, insults and personal attacks are not welcome in issues, pull
requests or anywhere else the project is discussed.

Report anything that breaks this to John Morris at
[john@johnmorris.ca](mailto:john@johnmorris.ca). Reports are read in confidence
and answered.
